ไม่มีการเชื่อมต่ออินเทอร์เน็ต

ระบบต้องใช้อินเทอร์เน็ตเพื่อดึงข้อมูลล่าสุด กรุณาเปิด Wi-Fi หรืออินเทอร์เน็ตมือถือ แล้วแอปจะเชื่อมต่อให้อัตโนมัติ

เชื่อมแอปกับระบบ

วาง URL ของ Web App จาก Google Apps Script (ลงท้ายด้วย /exec) เพื่อทดลองใช้งานบนเครื่องนี้

ค่านี้บันทึกไว้เฉพาะเครื่องนี้ ก่อนแจกแอปให้นักศึกษา ให้ใส่ URL ไว้ที่ CONFIG.GAS_URL ในไฟล์ index.html เพื่อให้ทุกเครื่องเปิดได้ทันที

ติดตั้งแอปบนหน้าจอโฮมเปิดใช้งานได้ทันที เหมือนแอปทั่วไป
