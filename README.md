# แอประบบรับสมัครฝึกงานและสหกิจศึกษา (CWIE App) v1.0.0

แอปสำหรับ **iPhone · iPad · Android · Windows · Mac** ครอบระบบ Google Apps Script เดิม (Code.gs + Index.html V10 + ส่วนนิเทศ NT v1.1.0)
ติดตั้งผ่านเบราว์เซอร์แบบ PWA ไม่ต้องผ่าน App Store / Play Store ไม่มีค่าใช้จ่าย และอัปเดตอัตโนมัติทุกครั้งที่แก้ระบบใน Apps Script

```
cwie-app/
├── index.html            ← ตัวแอป (★ ใส่ URL ของ Web App ที่บรรทัด 302)
├── manifest.json         ← ชื่อแอป ไอคอน ทางลัด
├── sw.js                 ← เปิดแอปเร็ว ใช้ออฟไลน์ได้
├── .nojekyll
├── icons/                ← ไอคอนทุกขนาด (iOS / Android / คอมพิวเตอร์)
└── vendor/qrcode.min.js  ← ตัวสร้าง QR Code สำหรับแชร์ให้นักศึกษา
```

---

## ติดตั้งระบบ (ทำครั้งเดียว ประมาณ 10 นาที)

### ขั้นที่ 1 — อัปเดต Index.html ใน Apps Script
1. เปิดโปรเจกต์ Apps Script → ไฟล์ **Index.html** → ลบของเดิมทั้งหมด → วาง **Index.html ฉบับใหม่** ทั้งไฟล์ → บันทึก
   (**Code.gs ไม่ต้องแก้ไข**)
2. **Deploy › Manage deployments** → กดดินสอ ✏️ → Version: **New version** → **Deploy**
   (URL เดิมไม่เปลี่ยน)
3. ตรวจการตั้งค่าให้เป็น **Execute as: Me** และ **Who has access: Anyone**
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### ขั้นที่ 2 — ใส่ URL ในแอป
เปิด `index.html` ของแอป บรรทัด **302** แล้ววาง URL:
```js
GAS_URL: 'https://script.google.com/macros/s/xxxxxxxxxxxxxxxx/exec',
```

### ขั้นที่ 3 — อัปโหลดขึ้น GitHub Pages
1. GitHub (บัญชี jugkritm20-cyber) → **New repository** ชื่อ **`cwie-app`** → Public → Create
2. **Add file › Upload files** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ (รวม `icons` และ `vendor`) → **Commit changes**
3. **Settings › Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
4. รอ 1–2 นาที แอปจะอยู่ที่ **https://jugkritm20-cyber.github.io/cwie-app/**

> ถ้าตั้งชื่อ repository เป็นอย่างอื่น ให้แก้ `APP_INSTALL_URL` ใน Index.html (บรรทัดประมาณ 5106) ให้ตรงกัน
> ค่านี้ใช้กับแถบ “ใช้งานเป็นแอปบนมือถือ” ที่จะแสดงเมื่อมีคนเปิดลิงก์ Apps Script เดิมบนมือถือ

### ขั้นที่ 4 — แจกให้นักศึกษา
เปิดแอป → เมนู **⋮** → **แชร์แอป / QR Code**
- เลือกหน้าที่จะเปิดได้ (หน้าแรก / ยื่นใบสมัคร / ส่งใบตอบรับ / เช็กสถานะ / ดาวน์โหลดเอกสาร / นิเทศสหกิจ)
- **บันทึกรูป QR** ไปพิมพ์ติดบอร์ด หรือ **แชร์ลิงก์** ลงกลุ่ม LINE
- ลิงก์ที่แชร์มี `?openExternalBrowser=1` → กดใน LINE แล้วจะเปิดใน Safari/Chrome ให้อัตโนมัติ (ติดตั้งแอปและแนบไฟล์ได้)

## วิธีติดตั้งบนเครื่องผู้ใช้

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| **iPhone / iPad** | เปิดลิงก์ใน **Safari** → ปุ่ม **แชร์** (ถ้าไม่เห็นให้แตะ ⋯ ก่อน) → **เพิ่มไปยังหน้าจอโฮม** → เปิด “เปิดเป็นเว็บแอป” (ถ้ามี) → **เพิ่ม** |
| **Android** | เปิดใน **Chrome** → แตะปุ่มสีเหลือง **ติดตั้งแอป** บนแถบด้านบน หรือ ⋮ → **ติดตั้งแอป** |
| **Samsung Internet** | ≡ → **เพิ่มหน้าลงใน** → **หน้าจอหลัก** |
| **Windows / Mac** | **Chrome / Edge** → ไอคอนติดตั้งท้ายช่องที่อยู่เว็บ · **Safari บน Mac** → ไฟล์ → เพิ่มไปยัง Dock |

แอปจะแสดงวิธีติดตั้งที่ตรงกับเครื่องของผู้ใช้ให้อัตโนมัติ (ปุ่ม **ติดตั้งแอป** หรือแถบแนะนำด้านล่างจอ)

## ความสามารถของแอป
- เปิดเต็มจอเหมือนแอปทั่วไป มีหน้าจอเปิดแอป ไอคอนบนหน้าจอโฮม รองรับรอยบากและขอบจอ iPhone
- **ทางลัด** (กดค้างที่ไอคอนบน Android / คลิกขวาบนคอมพิวเตอร์): ยื่นใบสมัคร · ส่งใบตอบรับ · เช็กสถานะ · นิเทศสหกิจ
- **ปุ่มย้อนกลับ Android**: ปิดหน้าต่างที่เปิดอยู่ → ย้อนแท็บก่อนหน้า → กดซ้ำเพื่อออกจากแอป
- **ปรับขนาดตัวอักษร** ปกติ / ใหญ่ / ใหญ่มาก (เมนู ⋮)
- แจ้งเตือนเมื่อขาดการเชื่อมต่อ และเชื่อมต่อใหม่ให้อัตโนมัติเมื่อกลับมาออนไลน์
- หน้าระบบปรับให้ใช้บนมือถือได้ดีขึ้น: แท็บเลื่อนแนวนอน ช่องกรอกไม่ซูมเองบน iPhone ปุ่มใหญ่กดง่าย
- เปิดผ่าน LINE / Facebook จะแนะนำให้เปิดในเบราว์เซอร์ก่อน (ในแอปเหล่านี้แนบไฟล์และติดตั้งไม่ได้)

## การอัปเดตภายหลัง
- **แก้ระบบ (Code.gs / Index.html)** → Deploy › Manage deployments › New version → ทุกเครื่องได้ของใหม่ทันที ไม่ต้องติดตั้งแอปใหม่
- **แก้ไฟล์ของแอป (โฟลเดอร์นี้)** → อัปโหลดทับใน GitHub แล้วเปลี่ยนเลข `CACHE_VERSION` ใน `sw.js` บรรทัด 7 ทุกครั้ง เช่น `cwie-app-v1.0.1`

## ถ้าต้องการขึ้น Play Store / App Store (ไม่บังคับ)
แอปแบบ PWA นี้ใช้งานได้ครบโดยไม่ต้องขึ้น Store
- **Google Play**: นำลิงก์แอปไปห่อเป็นแอป Android (Trusted Web Activity) ด้วยเครื่องมืออย่าง PWABuilder ได้ ต้องมีบัญชีนักพัฒนา Google Play
- **App Store**: ต้องมีบัญชี Apple Developer และเครื่อง Mac และ Apple มักไม่อนุมัติแอปที่เป็นเพียงหน้าเว็บห่อไว้ จึงแนะนำให้ใช้ “เพิ่มไปยังหน้าจอโฮม” แทน
